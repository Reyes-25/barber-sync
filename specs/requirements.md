# Requisitos Funcionales

1. **RF1:** El sistema debe permitir a un cliente ver los horarios disponibles de un barbero en una fecha específica.
2. **RF2:** El sistema debe permitir al cliente seleccionar un servicio (Corte, Barba, Corte+Barba).
3. **RF3:** El sistema debe permitir confirmar una reserva ingresando nombre y teléfono.
4. **RF4:** El sistema debe mostrar un mensaje de confirmación al cliente con los detalles de su cita.
5. **RF5:** El barbero debe poder ver la lista de sus citas agendadas para el día.
